# Markdownで記事を書く

記事は `articles` フォルダーに `.md` ファイルとして保存します。ファイル名が記事IDになり、一覧は日付の新しい順に自動表示されます。

```text
articles/
  20261115-hello.md
```

ファイルの先頭にタイトルと日付を書き、空行の後に本文を書きます。`---` で囲むYAML形式のヘッダーも使えます。

```markdown
title: はじめての記事
date: 2026/11/15

# 見出し

本文を書きます。**太字** や *斜体*、`コード` が使えます。

- 箇条書き
- もう一つ

[リンク](https://example.com)
```

```markdown
---
title: YAML形式の記事
date: 2026/11/16
---

## 小見出し

本文です。
```

見出し、段落、箇条書き、番号付きリスト、引用、コードブロック、リンクに対応しています。PHPが記事ファイルと `likes.json` を読み書きできる状態でサイトを動かしてください。
